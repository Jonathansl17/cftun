==========================
 GUÍA COMPLETA: CLOUDLFARED + TÚNEL + PROYECTO NODE/FRONT
==========================

Esta guía es una referencia completa para crear un túnel de Cloudflare desde cero, 
conectar tu API (Node.js o Express) y tu frontend (React/Vite/Next), sin usar Nginx.  
Todo por túnel. Todo en el mismo dominio.

────────────────────────────────────────
 1. PRERREQUISITOS
────────────────────────────────────────

• Tener un dominio agregado a Cloudflare (ej: mytry.dev)
• Tener Cloudflared instalado en el servidor:

sudo apt update
wget https://github.com/cloudflare/cloudflared/releases/latest/download/cloudflared-linux-amd64.deb
sudo dpkg -i cloudflared-linux-*.deb

• Autenticarte con Cloudflare:

cloudflared login

Esto abrirá un enlace. Seleccionás tu dominio.

────────────────────────────────────────
 2. CREAR EL TÚNEL PRINCIPAL
────────────────────────────────────────

cloudflared tunnel create mytry-tunnel

Esto genera:
✓ Un ID del túnel (UUID)
✓ Un archivo JSON de credenciales en: /home/USUARIO/.cloudflared/UUID.json

Ejemplo:
Tunnel credentials written to:
/home/jserver/.cloudflared/594e106e-8835-4117-a815-752fe2c77902.json

────────────────────────────────────────
 3. CONFIGURAR EL ARCHIVO CONFIG.YML
────────────────────────────────────────

Usá siempre el mismo túnel para el API y el front.

Editar archivo:
sudo nano /etc/cloudflared/config.yml

Contenido recomendado:

tunnel: 594e106e-8835-4117-a815-752fe2c77902
credentials-file: /home/jserver/.cloudflared/594e106e-8835-4117-a815-752fe2c77902.json

ingress:
  - hostname: mytry.dev
    service: http://localhost:5174

  - hostname: api.mytry.dev
    service: http://localhost:5000

  - service: http_status:404

Explicación:
• Frontend → corre en puerto 5174
• Backend (API) → corre en puerto 5000
• Todo por túnel, sin nginx.

────────────────────────────────────────
 4. CREAR LOS DNS AUTOMÁTICOS DEL TÚNEL
────────────────────────────────────────

cloudflared tunnel route dns mytry-tunnel mytry.dev
cloudflared tunnel route dns mytry-tunnel api.mytry.dev

Esto crea CNAME automáticamente.

────────────────────────────────────────
 5. INSTALAR EL SERVICIO SYSTEMD (para que arranque solo)
────────────────────────────────────────

sudo cloudflared service install
sudo systemctl enable cloudflared
sudo systemctl restart cloudflared
sudo systemctl status cloudflared

Debés ver:

Active: active (running)

────────────────────────────────────────
 6. INICIAR TUS PROCESOS BACKEND Y FRONTEND
────────────────────────────────────────

BACKEND (Node API):
cd /home/jserver/proyecto1-diseno/server
npm run server:dev   (o npm start si es producción)

FRONTEND:
cd /home/jserver/proyecto1-diseno
npm run dev   (o npm run build && npm start si es producción)

────────────────────────────────────────
 7. VERIFICAR LOCALMENTE
────────────────────────────────────────

curl http://localhost:5000/health
→ Debe responder JSON

curl http://localhost:5174
→ Debe mostrar frontend

────────────────────────────────────────
 8. VERIFICAR DESDE INTERNET
────────────────────────────────────────

curl https://mytry.dev
→ Debe cargar el frontend

curl https://api.mytry.dev/health
→ Debe cargar tu API

────────────────────────────────────────
 9. ERRORES COMUNES
────────────────────────────────────────

ERROR 1016:
→ La ruta DNS no apunta al túnel correcto.
Solución: volver a crear DNS:
cloudflared tunnel route dns mytry-tunnel mytry.dev
cloudflared tunnel route dns mytry-tunnel api.mytry.dev

ERROR "connection refused":
→ Backend no está corriendo en localhost:5000

ERROR “cannot find credentials file”:
→ Colocaste mal el UUID o borraste el JSON.

────────────────────────────────────────
 10. REGLA GENERAL
────────────────────────────────────────

• SOLO USÁS 1 túnel.
• Dentro del túnel ponés TODAS tus apps.
• No usás nginx para nada.
• Solo Cloudflare Tunnel enruta todo.

────────────────────────────────────────
 12. COMANDOS ÚTILES
────────────────────────────────────────

Ver túneles:
cloudflared tunnel list

Ver config:
cat /etc/cloudflared/config.yml

Reiniciar servicio:
sudo systemctl restart cloudflared

Logs:
sudo journalctl -u cloudflared -f



Entonces en general al editar el .yaml y crear el dns es

-hostname: subdom.mytry.dev
service: http://localhost:port

Y luego para crear el dns es

cloudfared tunnel route dns  mytry-tunnel hostname
